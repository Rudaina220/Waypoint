# Waypoint — Study Trail

A simple AI-powered study assistant for managing study tasks, taking quizzes, and asking AI questions.

## Features

- Study task tracking
- Quizzes
- AI study assistant
- Progress tracking
- Browser-based

## How to Use

1. Open `index.html` in your browser.
2. Add your study tasks.
3. Mark tasks as completed.
4. Use quizzes and the AI assistant when needed.
5. Add your Groq API key in Settings to use the AI features.

## Run Locally

No installation is required. Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Technologies

HTML, CSS, JavaScript, Groq API, and Local Storage.
